# Annadhanam 2.0

Food Donation and Redistribution Mobile & Web Application built with React Native and Expo.

## Overview
Annadhanam 2.0 connects food donors (restaurants, caterers, individuals) with recipients (NGOs, shelters, community centers) and administrators to minimize food waste and support communities in need.

## Features
- **Donor Portal**: Create and track food donations, schedule pickups, view donation history.
- **Recipient Portal**: Discover available food donations, submit requests, and track deliveries.
- **Admin Dashboard**: Verification, approvals, and platform metrics.
- **Live Tracking & Maps**: Real-time status tracking for active deliveries.

## Tech Stack
- **Framework**: Expo / React Native
- **Navigation**: React Navigation (Native Stack & Bottom Tabs)
- **UI Components**: Custom components with theme support (`src/theme/theme.js`)
- **Icons**: `@expo/vector-icons`

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn
- Expo Go app on iOS/Android (for testing on mobile)

### Installation
```bash
npm install
```

### Running the App
```bash
# Start the Expo development server
npm start

# Run on Web
npm run web

# Run on Android
npm run android

# Run on iOS
npm run ios
```
